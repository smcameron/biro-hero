biro-hero
---------

This is just a little game I put together for a game jam.

It's meant to be rendered along the lines of what a kid would
draw in his notebook with a ball point pen. There's a big underground
bunker system with little guys running around doing battle.

Arrow keys to move, space to jump, Z to fire, X for grenades.

Probably contains bugs, probably is incomplete and unfinished.
